# 🛠️ ServiTech

> **ServiTech** es un sistema inteligente de agendamiento y gestión de citas diseñado para optimizar el flujo de atención, diagnósticos y contingencias en talleres de servicio técnico de celulares y computadores.

---

## 📌 Características Principales

* ⏱️ **Gestión de Citas por Especialidad:** Selección de diagnósticos, reparaciones exprés, entregas y garantías.
* 🔄 **Flujos de Contingencia Automáticos:** Manejo de retrasos, avisos de tiempo real, cancelaciones en 1 clic y *no-show*.
* 🧑‍💻 **Asignación de Técnicos:** Filtrado de agenda según la especialidad requerida (ej. Microsoldadura, Laptops, Mac, Android).
